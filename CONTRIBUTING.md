# Contributing

Thanks for improving Script Doc Sync.

## Local Setup

```bash
npm install
npm run check
```

## Development Rules

- Do not execute package scripts.
- Keep parsing deterministic and conservative.
- Add tests for new package-manager command forms.
- Keep reports useful for both humans and agents.

## Pull Requests

Please include:

- sample README text
- sample package scripts
- verification output from `npm run check`
